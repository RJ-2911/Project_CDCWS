# Community Driven Collaborative Workspace

This repository contains the SGP Semester 7 project for a collaborative workspace that combines an infinite canvas, content blocks, real-time collaboration, community sharing, and board export.

## Application

The active Vite/React application is in [`CCWS`](CCWS). Run it from that directory:

```powershell
cd CCWS
npm install
npm run dev
```

See [CCWS/PROJECT_STRUCTURE.md](CCWS/PROJECT_STRUCTURE.md) for the frontend, backend template, shared contracts, database, documentation, and test layout.
