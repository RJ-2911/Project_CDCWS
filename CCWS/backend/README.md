# Backend Template

NestJS service boundary for the CCWS platform.

## Planned modules

- `auth`: Better Auth integration and protected access.
- `boards`: board CRUD, permissions, and version history.
- `collaboration`: Socket.IO rooms and board events.
- `content-blocks`: document, spreadsheet, slide, drawing, and shape data.
- `community`: publishing, comments, reactions, bookmarks, and duplication.
- `export`: PDF and PNG export jobs.
- `database`: PostgreSQL client, migrations, and repositories.
